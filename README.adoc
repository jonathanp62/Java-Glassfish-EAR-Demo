Glassfish-EAR-Demo
------------------

A demonstration of a basic EAR application running Glassfish 8.

== Gradle Tasks for Glassfish deployment

Add the --no-configuration-cache option to disable the configuration cache as needed.

[options="header"]
|=======================
|Task Name        | Application Invocation
|:demo-ear:build  | No arguments
|:demo-ear:deploy | No arguments
|:demo-ejb:build  | No arguments
|:demo-war:build  | No arguments
|=======================

The demo-ear.ear file is created in the demo-ear/build/libs directory.

Current version: 0.1.0.
~~~~~~~~~~~~~~~~~~~~~~~
